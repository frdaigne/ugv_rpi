SERVO SETUP

For the first time use of this Pan-Tilt, you will need to follow these steps to configure the servo IDs and middle position:

Tilt Servo ID: 1 Pan Servo ID: 2

The default ID of both servos is 1. The Pan Servo ID must be changed to 2.

1

Disconnect the wire of the Tilt Servo. This ensures you are only setting the ID of the Pan Servo.

2

Click [Set Pan ID] to configure the current servo as Pan Servo (sets its ID to 2).

Set Pan ID
3

Reconnect the Tilt Servo wire.

4

Click [Release] to unlock the torque lock on both servos, then manually adjust to center position.

Release
5

Manually adjust the gimbal so the camera points straight ahead.

6

Click [Middle Set] to save the current position as the center.

Middle Set
7

Test the Pan-Tilt movement to verify normal operation.

8

If the Pan-Tilt is not operating correctly, redo the entire process.

Note: If you skipped step 1 (Tilt disconnected), both servo IDs will be set to 2. Use [Set Tilt ID] to restore ID 1, then restart the process.

Set Tilt ID
